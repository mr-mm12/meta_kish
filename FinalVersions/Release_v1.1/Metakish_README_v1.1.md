## Installation Guide

**Step 1:**  
Download all 5 compressed files from the `Release_v1.1` folder.  

**Step 2:**  
Place all the downloaded files in a single folder and select all of them.  

**Step 3:**  
Right-click on one of the files and choose **"Extract files"**, then click **"OK"**.  

**Step 4:**  
You will be asked for a password. Enter it carefully, making sure not to change any lowercase/uppercase letters or spaces.   password = It_is_just_getting_started
