# 🌴 MetaKish

**MetaKish** is a game development project that aims to recreate the beautiful island of **Kish** as an **online metaverse world** Starting from May 2, 2025.  

In this world, players will be able to:
- Explore a fully recreated virtual Kish Island.  
- Interact and socialize with other players.  
- Collect **Kish Coin**, an in-game cryptocurrency with **real-world value**.  

---

## 🎯 Project Goals
- Build a metaverse inspired by Kish Island.  
- Integrate blockchain technology to power a digital economy using **Kish Coin**.  
- Provide players with both entertainment and financial opportunities.
